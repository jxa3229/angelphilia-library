# 前端优化维护约定

- 当前项目是 Vue 3 / Pinia 静态站，默认发布分支为 main。维护改动保留在当前用户指定开发分支，发布需要用户授权。
- 首页与侧栏只读取 `librarySummary.json`。变更任一馆藏源索引后运行 `npm run sync:summary`，并执行 `node scripts/summarize-library.mjs --check`。dev/build 已按顺序集成；不要把完整索引同步 import 到应用 shell。
- 最近条目表示最近已知发行年份，未知年份排后；统计跨度只使用有效数字年份，不依赖未知项是否存在。
- HTML 清理必须先递归再展开未知标签。执行性标签整棵移除，事件属性与不安全协议删除。使用真实浏览器 DOM 测试覆盖嵌套父标签，不能只测试普通 p/div。
- 馆藏与限定详情用 `query.record` 对应稳定 folder/detailKey；同页 query 更新保留组件实例。浏览器历史与页面关闭入口均需回归，避免只更新内存 activeRecord。未知 ID 提供回到列表。
- 外装分类存稳定英文 key，展示标签按语言计算。搜索索引预生成并涵盖三语常用标题；商品原名与日文描述保留，详情不截断，原文标注 `lang="ja"`。未知专有名称保留原名，不臆造译名。
- 日文标题词典按最长短语优先、单次替换，先规范全角英数字。保护 Pink Drops、ANGEL PHILIA 等品牌，避免颜色词破坏名称，也避免较短的 Whitey 词条先吞掉 Super Whitey。扩充词典时同步验证这些边界。
- 配件组合与预览分别由 `useBodySelection` / `usePartPreview` 管理，不改变数据源和尺寸计算逻辑。修改后验证预设、手动选择、头围开关、预览筛选与相关档案。
- Windows Node 测试不要依赖 shell 展开 glob。`npm run test:unit` 通过 Node 枚举测试文件，兼容 Windows / Linux。
- 浏览器测试用 `./#/...` 相对地址，确保 `PLAYWRIGHT_BASE_URL` 的部署子路径不会被根路径覆盖。生产验证设置 `PLAYWRIGHT_PREVIEW=1`，使用预先构建的产物；必须在 build 后执行，不能以 dev 回归替代。
- 临时脚本、构建目录、浏览器和预览服务逐项登记并在收尾清理；正式封面缓存和长期回归测试保留。

## 常用验证

```powershell
npm.cmd run test:unit
npm.cmd run validate:body-parts
node scripts/summarize-library.mjs --check
node scripts/cache-catalog-covers.mjs --check
```

需要浏览器验证时串行运行完整 `npm.cmd run test:e2e -- --workers=1`。生产 Pages 验证使用 `http://127.0.0.1:5108/angelphilia-library/`，详细场景在 `tests/optimization.spec.js`。
