# 拼图资源托管与分享

## 范围与入口

两张无字拼图保留原始 PNG（1800 × 2400），另外新增黑底 PNG 和用于速览背景的 1080 × 1440 WebP。原图按文件复制，不能重编码、缩图或覆盖本地交付文件。黑底版只调整画布与拼图留白，照片区域保留原像素。

| 内容 | 原图 | 黑底版 | 分享页 |
| --- | --- | --- | --- |
| 35 位头像 | `public/images/doll-heads.png` | `public/images/doll-heads-dark.png` | `#/image/doll-heads` |
| 12 格兔耳与娃衣 | `public/images/bunny-outfits.png` | `public/images/bunny-outfits-dark.png` | `#/image/bunny-outfits` |

黑底分享页在对应 ID 后追加 `-dark`。资源清单和三语文案在 `src/data/sharedImages.js`；图片文件名使用固定 ASCII 名称，外部引用不依赖本机中文目录。

## 交互与验收

- 图书馆速览的头图和资料面板分别使用两张黑底 WebP，并叠加深色遮罩保证文字可读；公开首页不展示“拼图原图”区块或分享页入口。
- 拼图工具为整理者个人使用：在首页连续按三次 `0` 打开现有隐藏面板，再选择拼图链接；进入图片页后面板自动关闭。此方式仅隐藏入口，静态资源及分享 URL 不构成访问权限控制。
- 分享页支持直接访问、刷新、原图/黑底版切换、打开图片、下载 PNG、复制图片直链及分享页链接，图片按原比例完整展示。
- 缺失 ID 显示返回速览入口；加载失败提供重试；剪贴板受限时显示提示，保留下方可选中复制的完整链接。
- 支持中文、English、日本語和现有主题；390px 窄屏不出现横向滚动。
- 外部网站的 Markdown / HTML 图片嵌入使用 `/angelphilia-library/images/*.png` 直链；`#/image/...` 是网页分享链接，不能作为图片地址。
- 原图发布前比较源文件 SHA-256；图片请求应返回 `image/png`，尺寸应为 1800 × 2400。Pages 子路径使用现有 `assetUrl()`，不能硬编码站点根目录 `/images/`。

## 发布与验证

实际远端主分支为 `main`。本功能从最新 `origin/main` 建立独立功能分支，验证后完整合入 `main`，由现有 Pages workflow 发布。两张原图及新增黑底衍生资源是用户明确要求的正式托管内容，应纳入 Git；`outputs/` 中其他本地交付物继续保留原约定，不随本功能上传。

验证使用现有 Node 单元测试、部件数据校验、依赖审计、Vite 生产构建和 Playwright 单浏览器回归。新增 `tests/image-pages.spec.js` 覆盖分享、下载、复制、三语、窄屏、失败恢复和两张速览背景。额外使用带 `/angelphilia-library/` 的生产构建检查静态资源与直接刷新，不能只验证开发服务器根路径。

Windows 下 Node 不一定展开 `tests/*.test.mjs`；应由 PowerShell `Get-ChildItem` 枚举后以参数数组传给 `node --test`，避免把 glob 当作实际文件名。

Pages workflow 在 smoke 阶段也设置 `BASE_PATH=/angelphilia-library/`，开发服务器会按此路径提供资源。剪贴板、下载和分享链接的端到端断言必须结合 Playwright `baseURL` 与 `BASE_PATH` 生成预期地址；禁止写死 `http://127.0.0.1:5107/images/`。本地根路径通过不等于 CI 子路径通过；提交前须使用相同的 `BASE_PATH` 执行回归。
