# 更新日志维护约定

- 更新记录维护在 `src/i18n/dictionary.js` 的三语 `updateLogEntries` 中，每项包含实际更新日期 `date` 和面向访客的简述 `text`。描述已经完成的页面变化，不把计划或未实现内容写成发布成果。
- `useChangelogStore` 按日期从新到旧排序；图书馆速览的日期直接读取第一条日志，不另行维护独立的 `lastUpdated`。同一日期的记录保留原顺序，历史记录不覆盖。
- `ChangelogDialog.vue` 只在 App 中挂载一次。左下角入口和速览日期均调用同一个 store 的 `open()`，共用弹窗与记录。每次打开默认显示最近三条，可切换完整记录。
- 仓库说明位于左侧默认收起的“更多”下，保留原有页面和路由。

本次 2026-11-17 记录覆盖限定档案与术语、编号名录、简化卡片、头型号/肤色筛选、选项显示修复、仓库说明折叠及日期共用更新日志弹窗。回归验证两处入口只有一个弹窗、最新日期一致、完整历史可查看、重开恢复最近三条、三语文案及窄屏布局。
