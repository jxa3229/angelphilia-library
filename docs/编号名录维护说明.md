# 编号与角色名录

## 资料与范围

`src/data/dollRoster.js` 根据用户提供的 VMF50、Dollcore、版权联动和 Pink Drops 名单整理，共四组 104 项；名录项数不代表历史发行总数。名录只提供导航，不覆盖现有馆藏的规格、年份或发行信息。ONE SELECTION DOLL 条目只有通用名称，没有具体角色名，因此不列入角色名录，相关档案仍保留在馆藏与限定档案中。

- VMF50 Image Girl #01–#13，归属 Yamato。
- Dollcore #01–#04，归属 Yamato × Real Art Project。
- 三款早期版权联动，无连续编号。
- Pink Drops #01–#84，归属 Real Art Project；#41 仅保留待补名称位置。

## 匹配与资料差异

`src/utils/dollRoster.js` 使用完整馆藏集合匹配，不受页面当前筛选限制。先判定品牌，再比编号与名称；统一全半角、大小写和编号前导零。拉丁名字按完整词匹配，避免 MIU 命中其他长名称。缺少编号时，只允许品牌内唯一的名称别名匹配。多个版本全部保留，不自动挑一款。

- Pink Drops 优先根据 series 判断；旧资料中部分条目 group 为 VMF50 或 RealArtProject，不能只用 group 判断。
- Dollcore 与 Pink Drops 都有伽琉羅等名字，编号体系独立，不互相链接。
- Manami 在附件中对应多个不同编号，不能用缺号的 Manami 建立多重推断链接。
- 附件 #35 同时提到小夏，但本站小夏属于 #59；#35 仅按真由美 / Mayumi 匹配。
- 附件 #22 为絵里奈，本站为愛麗奈（エリナ），保留差异，暂不自动链接。
- 附件 #82 为莉乃 / Rino，本站名为 RINA，现有来源 URL 同时含「莉乃」和 RINA，因此显式加入 RINA 别名，并在英文栏保留两种拼写。
- 未匹配与未公开名称条目显示当前语言的状态文字，不生成可点击入口。

## 交互与维护

`DollRoster.vue` 复用馆藏页的 `openRecord`，名录和品牌分组默认收起。同名多版本展开后选择对应馆藏。组件通过 `v-show` 在详情期间隐藏，返回时保留名录、品牌及版本列表的展开状态，沿用原有筛选和滚动恢复。

新增或修正名称时，维护三语名称及可验证别名；禁止按相似发音、同编号或疑似译名强行连到其他角色。实际年份与规格仍由馆藏详情维护。不要为验证执行会重新生成资料的 npm build/dev 脚本。

验收覆盖默认收起、四个分组、跨品牌同号、重名与缺号、多版本选择、打开返回、语言切换及窄屏排列。匹配逻辑测试使用 `node --test tests/doll-roster.test.mjs`，页面回归复用已有预览服务，构建使用 Vite `build({ build: { write: false } })`。
