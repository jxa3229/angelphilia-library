# 馆藏筛选约定

- 馆藏卡片与完整索引共用 library store 的筛选状态。搜索、馆别、年份、来源、头型号和肤色取交集；重置清除全部条件，打开详情再返回保留条件。
- 头型号只读取 `headType`，不从角色名、身体配置或头部描述推断；缺少型号归入“未明”。
- 肤色仅对筛选值规范化，详情仍保留来源字段。白肌、White / Whitey / Whity、ホワイティ归入白；超白肌、Super Whitey、スーパーホワイティ归入超白；褐色与 Tan 归入褐。普通肌独立列出，多种肤色同时出现归入混合肤色；未确认、未完整确认和见官方规格归入未明。
- 分类键与当前语言无关，切换语言保持筛选。选项来自完整馆藏，避免组合筛选后当前选项消失，零结果沿用现有空态。
- 筛选控件桌面三列、中等宽度两列、手机单列，不横向溢出。

规范化规则在 `src/utils/libraryFilters.js`，对应单元测试在 `tests/library-filters.test.mjs`，组合筛选、空态、详情返回、重置及语言切换由 `tests/smoke.spec.js` 验证。Element Plus 非搜索型选择框的内部 input 会被 placeholder 覆盖，浏览器回归应点击可见选择框或以 combobox 的 Enter 键展开，不强制点击被覆盖的内部 input。

## 预览页热更新

如果新增筛选后，一直打开的预览页出现空选项、默认英文 Select 占位，但重新加载页面正常，先检查 Pinia store 是否接入 `acceptHMRUpdate`。仅更新组件不会替换已经创建的 store：旧实例可能缺少新 state、getter，文案 store 也可能继续引用旧词典。馆藏与偏好 store 均使用 Pinia 官方 HMR 接口，更新后保留已有筛选、语言和主题。

复现与验证：在独立浏览器中模拟旧馆藏 store 缺少头型号、肤色字段及旧词典缺少占位文案，保持页面打开触发代码热更新；确认不刷新页面即可恢复两个下拉框的选项和中文占位，并保留已输入的搜索词与主题。临时源码标记必须在 finally 中恢复，关闭本次浏览器会话。暗色模式下以鼠标展开两个选择框、选择 D 和褐色，确认只显示对应 RISA 档案。
