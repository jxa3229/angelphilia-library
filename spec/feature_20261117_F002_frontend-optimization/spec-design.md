# 整体前端优化设计

## 背景与范围

承接整体代码审查与已完成的馆藏图片专项；用户已授权继续处理。沿用 develop 本地现场，不创建分支、不提交或部署。静态 Vue 3 / Pinia / Vite 项目，不涉及数据库。

## 方案与交互契约

采用局部渐进优化；相比引入虚拟列表或重新组织全部资料，复用现有卡片、筛选、详情和批次展示，降低回归范围。

- 安全：先递归清理子节点，再展开不支持的标签；移除执行性元素，仅允许明确安全的链接协议。
- 最近条目按已知发行年份降序排列，未知排末；年份跨度仅由有效年份计算。
- 首页与侧栏读取构建时生成的小摘要；馆藏、限定档案、总索引按路由加载完整数据，加载中及失败时提供三语反馈与重试。摘要与原索引同步生成、校验。
- 外装首批 24 条，每次追加 24 条；筛选覆盖全量，变化后重置批次，切语言保留分类选择。预先生成搜索文本。详情显示完整清理后的原文，并标明日文来源。
- 中英日外装标题、类别及术语页正文随语言切换；document lang 同步，原商品名称和来源保留。
- 馆藏与限定详情使用 query.record 稳定标识，刷新与分享可恢复；浏览器前进后退与关闭详情一致，返回保留筛选、批次及滚动。无效标识显示提示及返回入口。
- 配件阁提取组合选择和预览逻辑为 composable，保持页面结构及交互。
- CI 先单元测试与资料校验，再构建，再用 Pages 子路径的生产预览运行浏览器回归；同步架构文档。

桌面与 390px/320px 验收：加载及错误入口可见，详情抽屉可关闭，分页不影响全量筛选，切换语言不产生水平溢出。保持上一轮本站封面缓存与失败恢复。

## 验收标准

- 嵌套未知标签、危险协议及执行性内容无法绕过白名单，正常格式与安全链接保留。
- 未知年份不会置顶；无未知年份时也不漏掉年份上限。
- 首页不请求三个完整馆藏数据模块；摘要与全量统计一致。
- 383 条外装可分批访问，长正文尾部可读，三语常用标题/分类和术语正文正确；商品专名与原始日文说明保留。
- 馆藏及限定详情支持直达、刷新、前进后退、无效 ID 和列表返回。
- 配件阁组合码、预设、尺寸与预览回归通过。
- 单元测试、资料校验、完整生产子路径浏览器回归与构建检查通过；清理本轮临时产物。
